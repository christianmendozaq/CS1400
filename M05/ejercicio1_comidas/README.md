# Programa de Comidas de Latinoamérica

## Objetivos de aprendizaje

- Usar `print()` para mostrar mensajes en la consola.
- Utilizar `input()` para recibir datos del usuario.
- Trabajar con variables.
- Aplicar el método `.lower()` para convertir texto a minúsculas.
- Implementar estructuras condicionales `if`, `elif`, y `else`.

## Instrucciones

1. El programa debe dar 5 opciones de comidas tradicionales de Latinoamérica.
2. Elige de una lista el nombre de una comida (quiza mas facil con numeros o si quieres aprender sobre REGEX usando los nombres tambien).
3. Al elegir recibirás un mensaje que explica de dónde es esa comida.
4. Si una seleccion no está en la lista, verás un mensaje de error o peticion para intentar de nuevo.

## Ejemplo de salida

Bienvenido al programa de comidas de Latinoamérica.
Opciones: tacos (y otras opciones)...
¿Sobre qué comida quieres conocer mas? Tacos
Los tacos son típicos de México.
